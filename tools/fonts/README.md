# Device Chinese font subset

Noto Sans SC, SIL Open Font License 1.1 (OFL.txt), upstream google/fonts `ofl/notosanssc/NotoSansSC[wght].ttf`. These C subsets contain printable ASCII plus actual Chinese UI strings, at 22 and 24 px, 4bpp. No full source font is shipped. Device 466px pages use Regular weight400; the variable source defaults to thin100, so instantiate first:

```python
from fontTools.ttLib import TTFont
from fontTools.varLib.instancer import instantiateVariableFont
font=TTFont("NotoSansSC[wght].ttf")
instantiateVariableFont(font,{"wght":400},inplace=True).save("/tmp/NotoSansSC-Regular.ttf")
```

Requires Python fontTools for this one-time input preparation, Node and lv_font_conv1.5.3. Run `tools/fonts/generate.sh /tmp/NotoSansSC-Regular.ttf`. For cached/offline conversion set LV_FONT_CONV to installed lv_font_conv.js. Character file is regenerated from production UI strings. Asset source comments are generated by lv_font_conv. No font generation at firmware build time.

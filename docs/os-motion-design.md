# 边缘卡片导航与 OS 过渡动画

固件 2.2.0。本规范替代 32 px 切页动画及面板任意位置返回规则。USB v2、Bridge API 和主机确认协议不变。

## 空间与层级

Face 为常驻底层，保留对象、各 Agent 表情时钟和业务模型。Agent 卡片在上方，用量卡片在下方；同时最多出现一张卡片，必须经过 Face 才能切到另一张。返回不重建 Face 或重播状态入场。左右边缘预留，不切换风格。

| 卡片 | 拉入 | 收起 |
|---|---|---|
| Agent | Face 顶部向下 | Agent 底部向上 |
| 用量 | Face 底部向上 | 用量顶部向下 |

466 × 466 的视觉尺寸：卡片停靠 (12,12)，大小 442 × 442，半径 221 的完整圆形遮罩；外部由实际圆屏裁切。Face、Agent 与用量页面统一纯黑 `#000000`，外壳不绘制边线。不模糊、不缩放全屏、不淡化眼睛、不交叉淡入淡出。圆形边缘随卡片一起移动，不能仅依靠物理圆屏裁切一个圆角矩形；层次由内容、把手和遮挡表达，不制造背景色差。内容安全区 x=70–396、y=62–404，仍须检查圆屏可见范围。保留原字体和内容层级。

返回把手 36 × 4、圆角 2，Agent 中心 (233,430)，用量中心 (233,36)。底部状态提示在 y=380–404，不覆盖把手。边缘候选期间把手以 100 ms 亮度过渡提示可拖动；Face 候选使用同位置的短暂提示。面板正文不增加无边缘约束的“上滑返回”文案。

## 输入归属

OS 仲裁直接使用屏幕坐标，不随表情旋转或重力微动改变。仅 Face 互动应用原有、整笔锁定的逆旋转映射。

- 顶部起点 y≤56，底部 y≥410；起点必须满足 `(x−233)²+(y−233)²≤233²`。
- 对应边缘开始、预期方向位移 **>12 px**、纵向至少横向 1.4 倍才锁定。锁定前不移动，锁定时扣除 12 px 死区。
- 正文触摸与边缘候选从第一次接触保持归属到全部手指离开。脸部滑到边缘不变导航，边缘触摸不连击、不转控件点击。
- 第二指、触点身份替换、取消或输入错误：清除释放速度并退回最近稳定端点，吞掉余下接触直到全部离开。第一笔唤醒只唤醒。
- 无位移长按不打开/关闭。Agent 正文横滑仅预览、中央卡片轻点提交；用量标签轻点切换，正文纵滑不返回。
- 拖动及吸附中禁止内容点击，露出的 Face 仅显示，不接收穿透触摸。

## 跟手、释放与弹簧

统一展开进度 `p∈[0,1]`，行程 466 px。Agent `y=12−466(1−p)`，用量 `y=12+466(1−p)`。有效手指位移和卡片位移 1:1，无缓动，可反向拉回。端点外位移 d 使用 `12d/(48+d)` 阻尼，最多 12 px，松手回归端点。

打开/收起完成距离达到行程 38%（177.08 px）则完成；有效移动至少 56 px 且同向速度 ≥650 px/s 可提前完成。反向释放速度达到 650 px/s 优先取消，返回最近稳定端点。速度仅取释放前 80 ms 的有效位置；不足两条、时间差为零或已停留超过窗口不作快甩判断。保留静止样本，不沿用过期速度。

松手从当前视觉位置及速度接续。临界阻尼弹簧 ζ=1、ω=24 rad/s；以解析解计算，避免帧率依赖：`x(t)=target+(x0+(v0+ωx0)t)e^(−ωt)`，其中 x0 为初始相对目标位移。距离 <0.5 px 且速度 <5 px/s 完成；最长 450 ms 精确停靠，典型 220–320 ms。端点阻尼释放时将速度按阻尼导数转换，保持视觉连续。时间戳回退不倒放弹簧。

吸附中可从对应边缘重新抓取同一卡片，沿当前位置接管；另一张卡片仍不可介入。接管后取消，返回最近一次已停稳的端点，未完成打开不能成为稳定页面。稳定端点只在吸附结束时提交。边缘候选未锁定时，原吸附继续运行。

## 内容和业务更新

Agent 预览朝手势方向移动 24 px、180 ms ease-out；连续操作读取当前偏移并接续，最新预览为目标。用量指示线 160 ms 移到目标标签，正文同步更新，外壳不动。点击以 80 ms 按下/120 ms 恢复的背景和边线反馈，不缩放文字。

Agent 提交仍等待主机确认：成功由同一弹簧收向上方，失败保留卡片、预览和错误提示。用户主动抓取返回边缘即结束本地自动收起意图，不撤销请求；浏览代次隔离迟到确认，确认不能重新打开卡片或干扰新一轮浏览。动作期间模型持续更新，不改变位置或重启动画。Face 隐藏时继续同步真实生命周期，停止无用表情绘制；返回按当前时钟采样。

## 实现入口

- `bot_core/include/bot_os_motion.h`：尺寸、颜色、触发距离、速度、阻尼与内部动画 token。
- `bot_core/navigation.c`：无分配状态机 Face → Dragging → Settling → Panel，保存卡片、展开位移、速度、目标和最近稳定端点。
- `bot_ui/ui.c`：完整帧先做导航仲裁，再交 Face 或正文；常驻 Face、按需创建并保留卡片容器。隐藏容器不绘制；正文数据按需要刷新。
- `bot_ui/ui_motion.c`：控件反馈、预览和指示线的对象动画。
- `tools/replay_os_ui.c`：真实生产 LVGL UI 的坐标回放工具，无替代动画引擎、无新增单元测试。传输仍是现有 host build，回放明确显示缺失数据。

## 验收规范

构建与现有检查、离线 UI 回放、实机验收分开报告。旧长按/横滑首页/纵滑标签/任意位置返回/即时切页断言单独列为旧契约，不静默修改断言。

1. 展开 0/25/50/75/100%：方向、Face 连续存在、卡片边距、把手、字体与圆屏裁切。
2. 慢拖、快甩、半途反向、短滑取消、停住释放、端点阻尼、吸附中抓取及连续开合。
3. 四个实体边缘、正文纵滑、第二指、输入取消、释放不误点、旋转后屏幕边缘一致、第一笔唤醒。
4. 主机确认、拒绝、迟到确认、标签、缺失数据、隐藏期间业务状态变化及 Face 时钟连续。
5. 记录真实设备帧提交耗时、长时间开合内存表现；相机/人眼检查黑帧、闪屏、残影和手感。主机软件渲染耗时不是面板扫描 FPS，构建通过不替代实机验收。

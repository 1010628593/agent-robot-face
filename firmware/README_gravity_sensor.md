# ESP32-S3 开发板重力感应功能说明

## 概述

本固件集成了重力感应功能，使用QMA7981加速度计传感器，当设备倾斜时自动旋转屏幕，使表情始终保持正向显示。

## 硬件支持

开发板硬件预留了QMA7981加速度计（I2C总线，GPIO14/15），本固件已启用该功能。

## 功能特性

1. **实时检测设备倾斜**：每20ms读取X、Y、Z轴加速度数据
2. **连续跟随旋转**：实时旋转UI，表情始终保持水平
3. **平滑插值算法**：避免旋转抖动，响应自然流畅
4. **低功耗设计**：每20ms检测一次，不影响系统性能

## 旋转逻辑

- **连续跟随模式**：旋转角度实时跟随设备倾斜角度
- **水平补偿**：设备倾斜时，UI反向旋转，保持表情水平
- **平滑插值**：使用平滑因子（0.3）控制跟随速度
- **任意角度旋转**：支持0-360度任意角度，非离散旋转

### 旋转原理

当设备向右倾斜30度时，UI会向左旋转30度，使得表情保持水平。旋转角度是连续的，不是离散的0°/90°/180°/270°。

### 平滑因子

- **平滑因子 0.3**：响应适中，跟随自然
- **平滑因子 0.5**：响应较快，跟随更紧密
- **平滑因子 0.1**：响应较慢，更平滑但延迟更高

## 代码结构

### 驱动组件
- `components/qma7981/`：QMA7981加速度计驱动
  - `qma7981.c`：驱动实现
  - `include/qma7981.h`：头文件和API定义

### 集成代码
- `main/main.c`：主程序，包含重力感应初始化和任务
- `managed_components/waveshare__esp32_s3_touch_amoled_1_75/include/bsp/esp32_s3_touch_amoled_1_75.h`：BSP配置，已启用IMU能力

## 编译和烧录

1. 确保已安装ESP-IDF v6.1
2. 编译固件：
   ```bash
   idf.py build
   ```
3. 烧录到开发板：
   ```bash
   idf.py -p /dev/ttyUSBx flash monitor
   ```

## 调试信息

固件会输出以下调试信息：
- 重力感应初始化状态
- 设备倾斜角度（俯仰角和横滚角）
- 屏幕旋转角度
- 错误信息（如I2C通信失败）

## 故障排除

### 1. 重力感应初始化失败
- 检查I2C连接（GPIO14/15）
- 确认QMA7981芯片焊接正确
- 检查I2C上拉电阻

### 2. 屏幕不旋转或旋转不连续
- 确认LVGL v9支持transform旋转
- 检查调试日志中的倾斜角度值
- 确认平滑因子设置合理（建议0.1-0.5）

### 3. 旋转抖动或不自然
- 调整平滑因子（降低值使旋转更平滑）
- 检查加速度计数据质量
- 确认I2C通信稳定

### 4. 旋转方向不正确
- 检查`target_angle = -roll`的符号
- 确认设备坐标系方向
- 根据实际硬件调整旋转逻辑

## 自定义配置

### 调整平滑因子
在`gravity_task()`中修改平滑因子：
```c
const float smooth_factor = 0.3f;  // 0.1-0.5，越大响应越快
```

### 调整检测频率
修改`vTaskDelay()`参数：
```c
vTaskDelay(pdMS_TO_TICKS(20));  // 20ms检测一次（50Hz）
```

### 调整量程设置
在`init_gravity_sensor()`中修改量程：
```c
.range = QMA7981_RANGE_2G,  // ±2g量程
```

### 调整旋转中心点
在`gravity_task()`中修改旋转中心：
```c
lv_obj_set_style_transform_pivot_x(scr, 233, 0);  // 屏幕中心X
lv_obj_set_style_transform_pivot_y(scr, 233, 0);  // 屏幕中心Y
```

## 注意事项

1. **圆形显示屏**：连续旋转可能导致部分内容超出圆形显示区域
2. **触摸坐标**：旋转后触摸坐标需要相应转换（LVGL自动处理）
3. **性能影响**：20ms检测周期，优先级5的任务，对性能影响较小
4. **功耗**：QMA7981功耗较低，但频繁检测会增加功耗
5. **LVGL版本**：需要LVGL v9支持transform旋转功能

## 扩展功能

1. **手势识别**：基于加速度数据识别特定手势
2. **运动检测**：检测设备运动状态
3. **自动休眠**：设备静止时自动进入低功耗模式

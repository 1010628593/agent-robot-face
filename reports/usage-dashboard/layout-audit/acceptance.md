# 3.2.4 圆屏用量布局修正

依据：用户确认的 design03 和后续同工具多额度同心环要求；本轮明确只处理圆屏用量。before/ 是本轮修改前生产代码的真实 LVGL 渲染，after/ 是修改后同样例数据渲染，不是设备照片，也不是正式账号数据。

发现并修复：页签选中圆点挤入相邻文字；两行网格尺寸不一致、图标与文字相交；费用显示过小且存在无意义单行中转列表；额度详情缺少已用语义且重置文本贴弧线；从详情换指标落到第一个模型；单页左右滑动没有明确作用。

1. 工具及维度总览：统一网格和原生图标尺寸；费用数值、币种分离；Token 取消不必要的小数。
2. 工具额度：保留阶段单色同心环，去掉与额度周期无关的“今日”切换控件。
3. 指标详情：扩大额度环，补齐已用，调整文本与环的距离；页签下方独立选中条。
4. Token / 费用：页签进入该指标入口，费用直接大数值；来源说明保留。
5. 手势：单页切指标、多页优先翻页；说明和返回层级保持明确。

验证：七张静态页面的局部重绘与完整重绘逐像素一致（partial-comparison.txt）；contacts/trace.csv 使用真实 LVGL 触摸路由进入 depth 1、点环进入 depth 2、滑动返回指标入口、费用、说明、逐层返回 depth 0。未增加单元测试。

ESP-IDF 正式构建通过，BOT_DEVICE_SOAK=OFF；固件版本 3.2.4。硬件与用户视觉反馈在烧录后记录，native CPU 时间不作为实机 FPS。

仍不代表全部设计验收完成：样例没有覆盖所有真实额度名称、极长模型名、费用极值和空态组合；四源完整生命周期与长期心跳稳定性另有验收缺口。

烧录读回：esptool 写入哈希校验通过，Bridge hello 确认 3.2.4；启动 35 秒，内部空闲 73,519 字节，无固件错误。Bridge reconnect_count=1 是本轮烧录前已有累计值，不能当成本次新重连。

### 3.2.5 边界复核

追加真实 LVGL 边界样例：100%、99.9%、32 字符模型名、协议上限附近费用、过期额度、全部无数据。发现从维度网格直进费用会显示未初始化分页标签 Text；已限制费用页分页标签可见性。总览小环的 100% / 99.9% 文字压环；改用 20px 紧凑整百分比显示（常规四舍五入），详情保留原始小数精度。费用高值使用现有 36px 字体降档，未发生遮挡。边界样例只存在 native review harness，没有投送为生产数据。

edges/contact.png 为修复前，本轮重新渲染；edges-after/fixed.png 为修复后。原版空态和过期样例不补零、不绘制彩色额度。

### 3.2.5 实机回放限制

第一轮保留上一轮层级，不能作为八次完整详情路径通过。已在仅诊断构建的 device_soak.inc 中每轮调用 stats_reset。修正回放后记录在 hil-3.2.5.json；期间再次出现 heartbeat_timeout 重连，无 SPI 分配错误。超时采样仍刚收到 uptime=60148ms 的 @heap 与绘制诊断，说明该次超时前 UI 线程仍在运行，不能称作 UI 死锁。通信尾项未解决，实机压力验收不通过。正常使用视觉反馈仍待用户；不能用 native 渲染通过替代。
